エグゼクティブ・サマリー

HPE Morpheus VM Essentials は、KVM / QEMU / libvirt / Open vSwitch / Pacemaker をベースとしたオープンソーススタックをエンタープライズ向けにパッケージ化した仮想化基盤です。VMware vSphere に近い管理感（HA、DRS相当のライブマイグレーション）を提供しつつ、ネイティブ移行機能（Migration Tool）により vSphere からのシームレスな移行を実現します。

アーキテクチャ & スタック構成

  • ハイパーバイザ基盤: Linux KVM / QEMU / libvirt / Open vSwitch を基盤に採用。
  • クラスタリング・HA: オープンソースの Pacemaker がコアとして稼働。
  • 統合パッケージ: HPE 提供の ISO により各コンポーネントが事前設定済みで展開。
  • 単一管理プレーン: VM Essentials Manager（vCenter 相当）から既存 vSphere と VME クラスタを一元運用可能。

HA 前提条件

  • 共有ストレージ: iSCSI または Fibre Channel (FC) 必須。
  • Heartbeat Target: クラスタ設定でストレージボリュームの Heartbeat を明示的に有効化。
  • 状態監視: GUI（Summary 画面）およびホスト CLI（pcs status など）の双方で Pacemaker 状態を確認可能。

推奨ネットワーク構成（物理NIC）

推奨: 物理 6 ポート構成
2 ポート: 管理用 Bond (VMkernel 相当)
2 ポート: 仮想マシン配信用 (Production VLAN)
2 ポート: 共有ストレージ (iSCSI MPIO 等)
最小: 物理 4 ポート構成

管理トラフィックを Production ネットワーク上の VLAN に相乗りさせることで、最小 4 ポートまでポート数を集約可能。

実機デモにおける検証動作

HA Failover 検証

3ノード構成でホスト3の電源断をシミュレート。Pacemaker がホスト障害を即座に検出し、フェンシングを実行。停止ホスト上の VM を別ホスト（ホスト2）へ自動再起動・再配置して復旧。

DRS 相当の負荷分散

HeavyLoad ツールで負荷をかけ、障害から復帰したホスト3へクラスタのリソース負荷分散ルールに沿って ライブマイグレーション で自動再配置。無停止でのワークロード平滑化を確認。

VMware からのネイティブ移行（Migration Tool）

解説動画: Bart Heungens 氏（HPE VM Essentials v8.0.8）

YouTube で視聴
Windows VM 移行における最重要ポイント:
移行先 KVM で起動させるため、事前に VirtIO ドライバ（ストレージ・ネットワーク）を対象 OS 内にインストール/インジェクションしておくこと が必須です。また、移行後の競合を防ぐため VMware Tools の事前アンインストール が推奨されます。

移行ステップとバックエンドの挙動

STEP 01

Windows 側事前準備

回復環境/コマンドプロンプト等を利用し dism で VirtIO ドライバ（viostor.inf, vioscsi.inf）をインジェクション。Guest Tools も導入。

STEP 02

プラン作成・マッピング

Tools > Migrations で移行プラン作成。Source（vCenter）と Target（VME クラスタ）を指定し、ネットワーク/データストアをマッピング。

STEP 03

自動エクスポート & 転送

プラン実行後、VMware 側で VM シャットダウンと OVF テンプレートのエクスポートが自動開始され、VME ターゲット側へデータ転送。

STEP 04

再構成 & パワーオン

KVM 仮想マシンとして自動プロビジョニング・パワーオン。Web コンソール接続、IP 割り当て、ネットワーク疎通を確認して完了。

移行プラン作成時のパラメータ対比

項目 移行元 (Source: VMware) 移行先 (Target: HPE VM Essentials) 備考
クラスタ / グループ vCenter クラスタ / リソースプール VME クラスタ / Resource Group 同一管理コンソールから選択
ネットワーク vSphere 分散/標準ポートグループ VME ネットワーク (OVS VLAN) IP 設定の引継ぎ・再割り当て

VMware 管理者視点でのまとめ

運用の親和性

KVM ベースでありながら、クラスタのクォーラム判定、Pacemaker による HA 再起動、リソース偏りに応じたライブマイグレーションなど、vSphere HA / DRS と同等のコア体験が GUI 上で違和感なく再現されています。

移行の現実解

バージョン 8.0.8 でネイティブの Migration Plan が整備されたことで、外部ツールを用いずに OVF 経由での VM 変換移行が可能になりました。OS 側の VirtIO ドライバ仕込みの段取りさえテンプレート化・自動化できれば、大量 VM の移行プロジェクトも現実的に進められます。
