Phase 01 / Setup

VME Manager 初期共通設定ガイド Administration > Settings

初回セットアップ完了後、クラスタ作成やVM展開を開始する前に管理者が確認・投入すべき共通基盤設定です。 通信不整合によるプロビジョニング停止や、ローカルディスク枯渇によるアプライアンス障害を未然に防ぎます。

1. Appliance Settings（アプライアンス基本設定）

Target: Administration > Settings > Appliance
設定項目 仕様・入力値 重要注意点・ハマりポイント（失敗例と対策）
Appliance URL エージェント自動インストールや通信で使用する既定URL
（例: https://vmemgr.example.com）
Protocol Restriction IPアドレス指定であっても、必ず https:// で記述すること（http:// は不可）。
  • 通信＆DNS（PTR）要件： 全HVMホストおよび展開される全VMから、ポート 443 / 80 で到達・正引きおよび逆引き（PTR）解決可能であること。導通がない場合、Agentのインストールが即座に失敗します。
  • 個別上書き： 特定のプライベートNW経由で通信させる場合は、Infrastructure > Clouds > Edit Cloud > Advanced Options の Alternate Appliance URL で個別上書き可能。
Internal Appliance URL (PXE) PXEブートサーバーが直接参照する内部URL NAT環境等で外部向けAppliance URLと異なる内部ルーティングが必要な場合のみ設定（未設定時は通常のAppliance URLを使用）。
API Allowed Origins CORSでAPIアクセスを許可するオリジン（ドメイン）リスト
Whitelist Caution 外部WebアプリからREST API呼び出しを行う際に設定。未入力時は全オリジン許可ですが、1件でも入力すると排他的ホワイトリストになります。
Skip Agent Install VMプロビジョニング時のAgent自動導入をスキップするフラグ エージェントレス運用時に有効化。ただし無効化すると、ゲストOS内部の詳細メトリクス取得や自動化タスク（Script実行）機能が制限されます。
Enable SSL Verification of Agent エージェント通信のSSL証明書検証を有効化 有効化する場合、アプライアンスに信頼された正当なSSL証明書（CA署名済み）がインストールされている必要があります。
Disable SSH Password Authentication パスワード認証によるSSHログインを禁止し、公開鍵認証のみに制限
Access Lockout Risk 有効化後に作成されたVM/ホストに即時適用されます。鍵の設定を怠るとゲストOSへアクセス不能になります。
Default Console Gateway リモートコンソール/VDI通信を仲介するWorkerノードの指定 外部から直接VMにアクセスできない分離ネットワーク構成時に設定します。
Max Option List Size REST API等で取得する動的オプションリストの最大件数（指定数値 × 1,000 件） 「1」と入力すると上限1,000件。巨大なペイロードによるアプライアンスのメモリ枯渇・パフォーマンス低下を防ぐための防壁です。

2. Proxy Settings（プロキシ設定）

Target: Administration > Settings > Appliance > Proxy Settings
設定項目 仕様・入力値 重要注意点・ハマりポイント（失敗例と対策）
Global Proxy Server Proxy Host, Port, User, Password, No Proxy（除外リスト）
  • 外部S3やパッケージリポジトリを取得する閉域環境で設定。
  • OS環境変数との整合： UI上の設定に加え、アプライアンスOS側の http_proxy, https_proxy, no_proxy の値とも一致させる必要があります。
Routing Loop Prevention Infrastructure > Network 側の設定で Bypass Proxy For Appliance URL にチェックを入れ、マネージャー自身のAPI通信が外部プロキシに吸い込まれないよう注意してください。

3. Provisioning Settings（プロビジョニング・ストレージ保存先設定）

Target: Administration > Settings > Provisioning
設定項目 仕様・入力値 重要注意点・ハマりポイント（失敗例と対策）
Deployment Archive Store テンプレート等を保存する既定ストレージプロバイダー
Critical: Disk Full Hazard 既定保存先はローカルの /var/opt/morpheus/morpheus-ui/ です。これを外部のNFS / S3バケット（Infrastructure > Storage で事前登録）に変更しないと、アプライアンスのOSディスクが満杯になり全サービスが停止します。
  • ローカル共有フォルダを使用する場合、OS側で chown -R morpheus-app:morpheus-app の権限設定が必須です。
Cloud-Init Settings Linux / Windows 展開時のグローバル初期ユーザー設定
Configuration Mismatch 仮想イメージ側で Cloud-Init Enabled をONにしているのに、OS側にパッケージが入っていない場合は即時エラーとなります。Cloud-InitなしのLinuxを展開する場合は、Library > Virtual Images で既存のユーザー/パスワードの事前登録が必須です。
Library Settings Catalog、Apps、Instances の各作成画面の有効化とメニュー順序設定 検証や運用で使わない不要なプロビジョニング手法をUIから非表示にして画面をシンプル化できます。
PXE Boot Settings Bare Metal プロビジョニング（PXE Boot）時の既定 root パスワード 物理サーバーのベアメタル自動展開を行う場合、初期パスワードを必ず変更してください。

4. License, Utilities & Logging（ライセンス・保守・ログ管理）

設定項目 設定パス / ファイル 仕様・運用手順・注意点
License Management Administration > Settings > License
  • 自動評価モード： 初回未投入時は30日間の評価ライセンス（Evaluation）が自動適用。
  • 制限事項： 期限切れまたはソケット上限（Used HVM Sockets）に達すると、新規VM作成や既存VMのマネージド変換が全面ロックされます。
  • 更新方式： 「Stack License」または「Replace Current License」を選択してUpdate。
Maintenance Mode Administration > Settings > Utilities
  • アクティブセッションやキューを排出し、アプライアンスの保守作業を安全に行うスイッチ。
  • HA構成時の注意： LBのVIP経由ではなく、対象ノードの実IPアドレスに直接ブラウザ接続して実行すること（VIP経由だと意図しないノードが停止します）。
  • morpheus-ui サービスを再起動すると、メンテナンスモードは自動解除されます。
Audit Log Retention /opt/morpheus/conf/logback.xml
# 監査ログ保持期間設定（HPE推奨値: 365日）
<maxHistory>365</maxHistory>

# 反映のためのUIサービス再起動
sudo morpheus-ctl restart morpheus-ui
  • 監査ログ保存先: /var/log/morpheus/morpheus-ui/audit.log
  • ログ保持期間を延ばす際は、アプライアンスのディスク容量を十分に確保しておくこと（ディスクフルになるとUIがダウンします）。
